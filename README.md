## Project Overview

This project focuses on analyzing **restaurant order data using MySQL** to understand sales performance, customer ordering patterns, and popular menu items. SQL queries were used to clean, explore, and analyze the data and generate meaningful business insights.

### Tools & Technologies

* MySQL
* SQL
* Relational Database Concepts

### Key Analysis

* Analyzed restaurant order and menu data
* Identified popular and high-performing menu items
* Calculated total orders and sales
* Analyzed revenue by category and item
* Used SQL queries such as `JOIN`, `GROUP BY`, `ORDER BY`, aggregate functions, and subqueries

### Objective

The main objective of this project is to demonstrate practical **SQL and MySQL skills** through a real-world restaurant data analysis problem.
